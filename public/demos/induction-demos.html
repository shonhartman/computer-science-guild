Invariants & Induction

Four things you can poke at while you talk. The thread through all of them: an invariant — a quantity that refuses to change no matter what you do. It makes the puzzle impossible and the game inevitable.

Induction is dominoes

To prove a statement P(n) holds for every n, you need two things:

1. Base case — knock the first domino. Show P(0) is true.
2. Inductive step — show each standing domino knocks the next: P(k) ⟹ P(k+1).

Get both and the whole row falls — every P(n) is true. Miss one link and everything past it stays standing. That second button shows exactly that failure.

Press “Knock the base case” to start the chain.

The 8-puzzle that can’t be solved

Slide any tile next to the blank. Watch the inversion count jump around — but its parity (odd/even) never flips. That frozen parity is the invariant.

Row move (sideways) changes inversions by 0. Column move (up/down) changes them by 0 or ±2 — always even. So odd stays odd, forever.

The start has 1 inversion (odd). The goal has 0 (even). You can never cross from odd to even — so the goal is unreachable. Try as long as you like.

An inversion = a pair of tiles where the bigger letter sits before the smaller one in reading order (left→right, top→bottom). The blank doesn’t count.

What you’re allowed to assume

Both prove P(n+1). The difference is how far back you can look for help.

Ordinary: assume only P(n) — the one step right before.
Strong: assume all of P(0) … P(n) — the whole history.

They’re equally powerful. Strong is just easier when P(n+1) leans on smaller cases that aren’t the previous one. Hit the unstacking button: proving P(8) means splitting into P(3) and P(5) — ordinary can’t hand you those.

The unstacking game

Rules: start with one stack of 8. Split any stack into two (sizes a and b). Score a × b. Keep splitting until everything is single blocks.

Click a gap in a stack to split it there. Or let it auto-play. Try wildly different strategies — you always land on 28.

Why: a × b is exactly the number of block-pairs separated by that split. Every pair gets separated once, so the total just counts all pairs: C(8,2) = 8·7/2 = 28.
