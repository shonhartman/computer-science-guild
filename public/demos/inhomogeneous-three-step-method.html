Inhomogeneous Recurrences

The Three-Step Method & The Rescue Rule

The Three-Step Method

Step 1
Solve Homogeneous
Set g(n) = 0. Find characteristic roots and write general solution f_h(n) with undetermined constants.
Step 2
Guess Particular
Match g(n)'s shape for f_p(n). If guess base matches a homogeneous root, multiply by n!
Step 3
Combine & Apply Bounds
Combine f(n) = f_h(n) + f_p(n), then use boundary conditions f(0), f(1) to solve for constants.

Ansatz Table (Particular Solution Guesses)

Forcing Term g(n) Standard Particular Guess Rescue Rule (If Guess Base = Root)
bⁿ (Exponential) A · bⁿ Multiply by n: (A·n + B) · bⁿ
Polynomial (degree k) Degree-k polynomial Multiply by n: nʳ · (Polynomial)
Mixed (bⁿ + n) Guess each piece, then add Apply n-multiplier fix only to the failing piece

Worked Examples Comparison

EXAMPLE 1: CLEAN CASE
Recurrence: f(n) = 4f(n-1) + 3ⁿ, f(1) = 1
1. Homogeneous root: α = 4
   f_h(n) = c₁ · 4ⁿ

2. Guess f_p(n) = A · 3ⁿ (Base 3 ≠ Root 4)
   A · 3ⁿ = 4(A · 3ⁿ⁻¹) + 3ⁿ
   ⇒ A = -3 (Works cleanly!)

3. Combine & Apply f(1) = 1:
   f(n) = (5/2)4ⁿ - 3ⁿ⁺¹
EXAMPLE 2: ROOT CONFLICT
Recurrence: f(n) = 2f(n-1) + 2ⁿ, f(0) = 1
1. Homogeneous root: α = 2
   f_h(n) = c₁ · 2ⁿ

2. Naive Guess f_p(n) = A · 2ⁿ (Base 2 = Root 2)
   A · 2ⁿ = 2(A · 2ⁿ⁻¹) + 2ⁿ
   ⇒ A = A + 1 (Contradiction!)

✓ RESCUE: Guess f_p(n) = (A·n + B)2ⁿ
   ⇒ A = 1, B = 0

3. Combine & Apply f(0) = 1:
   f(n) = 2ⁿ + n · 2ⁿ
